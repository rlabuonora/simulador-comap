Vista general

Estructura General

Todo escenario JSON tiene estos bloques de primer nivel:

{
  "company": {},
  "project": {},
  "employment": {},
  "exports": {},
  "decentralization": {},
  "sustainability": {},
  "iplus": {},
  "strategic": {}
}
Bloque

company

Campos numéricos

  • annualBillingUi: número
  • employees: entero

Campos categóricos

  • sector: industria, servicios, agro, turismo
  • isNew: true o false
  • isIndustrialParkUser: si o no

Actividad parque industrial

  • ""
  • actividades-industriales
  • servicios-logisticos
  • energia-solar
  • valorizacion-residuos
  • servicios-tic-biotecnologia
  • otras-actividades
Bloque

project

Valores posibles

  • ministry: miem, mef, mgap, mintur
  • filedDate: fecha YYYY-MM-DD

Campos numéricos

  • machineryUi
  • installationsUi
  • civilWorksUi
  • industrialParkUi
Bloque

employment

employment.base

  • women: número
  • youth: número
  • disability: número
  • others: número

employment.inc

  • total: número
  • women: número
  • youth: número
  • disability: número
  • others: número
Bloque

exports

Campos principales

  • currentExports: número
  • exportIncrease: número
  • indirectExports: array

Items de indirectExports

  • pct: número
  • initial: número
  • increase: número

iplus

Campos

  • amountUi: número
  • category: at, inn, id, none
Bloque

strategic

Campos generales

  • priorities: número
  • mefRenewableInvestmentUi: número
  • mineralEligibleInvestmentUi: número
  • mineralProcessingLevel: "", minima, intermedia, maxima
  • mineralTransformFlag: si o no
  • nationalComponent: si o no

Componente nacional

  • nationalGoodsUi: número
  • nationalGoodsTotalUi: número
  • nationalCivilWorksUi: número
  • civilWorksMaterialsUi: número

Campos MGAP

  • mgapRiegoFlag: si o no
  • mgapBioFlag: si o no
  • mgapLivestockFlag: si o no
  • mgapLivestockImprovement: birth-rate, herd-growth, flock-growth
  • mgapNaturalFieldFlag: si o no
  • mgapPescaFlag: si o no

Campos MINTUR

  • minturStrategicFlag: si o no
  • minturInvestmentZoneUi: número
  • minturInvestmentOutsideUi: número

Campos MIEM

  • miemEnergyFlag: si o no
  • miemHydrogenFlag: si o no
  • miemWasteFlag: si o no
  • miemBioFlag: si o no
  • miemPharmaFlag: si o no
  • miemAerospaceFlag: si o no
  • miemSatellitesFlag: si o no

Montos MIEM

  • miemEnergyInvestmentUi: número
